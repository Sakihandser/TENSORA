# 经典算例模型 / Classic demonstration models

本目录的脚本用 TENSORA 自身的建模、网格和设置校验代码生成项目根目录上一级（`D:\计算力学程序`）中的经典算例 JSON。模型用于复现经典实验场景、演示各工作区功能，精度取够看清现象即可。

| 脚本 | 作用 |
| --- | --- |
| `build-2d.cjs` | 启动本地服务和随包 Chromium，用 `normalizeScene` 读入草图<br>Triangle 生成网格（流固耦合模型改用 `gmsh-2d.cjs` 的分级网格），用应用自身的规范化函数写入各工作区设置并保存 |
| `build-3d.cjs` | 调用 `solid3d.meshSolid`（与“生成网格”相同的 Gmsh 路径），按几何位置识别体域与 CAD 面，写出三维模型快照 |
| `validate.cjs` | 通过应用的导入控件打开模型，记录“计算前检查”结果，点击运行按钮并截获请求，再用服务端适配器生成 CalculiX / PhAST / OOFEM / SU2 / OpenCourant 输入卡片；不启动求解器 |
| `models-2d.cjs`、`models-3d.cjs` | 各模型的几何<br>材料<br>边界条件与求解设置 |

```powershell
.\node-v24.21.0-win-x64\node.exe examples/classic-models/build-2d.cjs ..        # 全部二维模型
.\node-v24.21.0-win-x64\node.exe examples/classic-models/build-3d.cjs .. sloshing # 指定三维模型
.\node-v24.21.0-win-x64\node.exe examples/classic-models/validate.cjs ..\某模型.json
```

## 说明

- 二维绘图坐标精度约 0.1 mm、最小区域面积 1e-5 m²，所以毫米级试样（如 Miehe 1 mm 试样）放大后建模。
- PhAST 路径限 1 万节点、5 分钟；相场模型网格按 h ≤ l₀/2 控制在 2000–6000 节点，五个相场算例均已完整试算（28–100 s）。
- 单边缺口拉伸 / 剪切和三点弯曲梁的目标位移设在裂纹失稳贯穿之前：失稳那一步交错迭代超过 300 次上限（提高到 3000 次也超出 5 分钟），因此结果显示起裂和稳定扩展段。L 形板与巴西圆盘可算到完全断开。
- 三维损伤变形的增量数、加载方式不随三维模型保存，打开后沿用界面默认值（40 增量、力控制）。
- 二维流固耦合模型使用与 NACA 0012 算例相同的紧凑网格格式；在设置页点击“生成 / 更新网格”会改回均匀网格。
- 材料参数取自项目材料库，或在模型内嵌并在材料备注中注明来源。
