# 线弹性静力强度校核

材料库编辑卡可为每种材料选择一种准则。保存后，引用同一材料的所有区域同步；模型快照、JSON、TXT、二进制求解输入均保存 strengthCriterion。当前 TRI3 核心为各向同性小变形线弹性，可在计算页“静力模型 → 二维假设”选择平面应力或平面应变。拉为正，平面应力 σz=0，平面应变 εz=0、σz=ν(σx+σy)，安全图使用单元应力。云图中的等效应力仍为 von Mises，不随校核准则改变。

| 编号 | 准则 | 校核量与阈值 | 所需材料参数 |
| --- | --- | --- | --- |
| 1 | Rankine 最大主应力 | max(0,σi)/ft 与 max(0,-σi)/fc | 抗拉 ft、抗压 fc |
| 2 | Saint-Venant 最大主应变 | max(0,Eεi)/ft 与 max(0,-Eεi)/fc | ft、fc、泊松比 ν |
| 3 | Tresca 最大剪应力 | max(σi)-min(σi) 与 fy | 单轴屈服 fy |
| 4 | von Mises 畸变能 | √(σx²+σy²+σz²-σxσy-σyσz-σzσx+3τxy²) 与 fy | 单轴屈服 fy |

所有主值均包含第三方向。第二理论使用 Eεi=σi-ν(σj+σk)，平面应力包括 εz=-ν(σx+σy)/E，平面应变 εz=0；阈值按单轴线弹性 ft/E、fc/E 换算，不代表实测断裂应变。第一、第二理论兼顾拉压不同极限，两者同时超限时显示利用率更高的一项。达到极限（利用率≥1）即标为超限。未施加额外设计安全系数，混凝土卡中的平均抗拉强度与特征抗压强度也不能直接当成规范设计强度。

第三、第四理论的剪切屈服极限分别由 fy/2、fy/√3 得出，因此没有新增独立抗剪强度字段；实测剪切破坏强度不能直接代替这两个屈服阈值。

结果代码：0安全、1压缩超限、2拉伸超限、3屈服超限、4未完成校核。参数缺失时不显示绿色，也不混入不安全单元数量，而是单独统计未完成校核单元。第一、第二理论要求 ft、fc 均为正，即使当前载荷只产生一种应力符号，也不对材料作部分校核。

旧模型未保存准则时：有正屈服强度选第四理论，否则选第一理论。TXT 在材料行和单元行末尾追加 criterion 列；旧行无此列仍可读取。二进制输入版本3在版本字段后新增 int32 planeMode（0 平面应力，1 平面应变），核心继续接受版本1/2并默认平面应力；结果版本2在版本字段后新增 int32 planeMode，每单元 safetyCode 后追加 stressZz、strainZz 两个 double。结果解码器仍可读取版本1。TXT 头新增 PLANE_MODE，结果行末追加 stress_zz、strain_zz；场景 JSON 保存 staticPlaneMode。已有计算结果不会因修改材料而自动重新校核，修改后应重新计算。

## 本次数值补充（2026-10-29）

[GB/T 9439-2010 英文公开文本](https://www.codeofchina.com/pdf/16699672844712ff14d35be5110df.pdf) 资料性附录 A，表 A.1（PDF 第20页）给出 φ30 mm 试棒 HT200 抗压强度参考值 720 MPa、ν=0.26。本次填入材料库，并保留原抗拉牌号下限200 MPa。附录是参考数据，不是任意铸件本体的保证值。来源已加入材料的 sourceUrls 和备注，静态 materials.js 镜像同步。

金属库默认选 von Mises；未查得同一状态的抗压破坏强度时保留空白，不把抗拉极限或拉伸屈服值冒充抗压破坏数据。既有混凝土的抗拉/抗压参数保留。花岗岩和青砂岩是既有论文材料卡，缺少可追溯的同试样单轴强度；保留既有参数，并注明抗拉值与 JH2 静水拉伸 T 相同而有待核实，未用其他岩石样本覆盖。其第一/第二理论校核需补齐经核实的单轴抗拉、抗压数据。

准则参数参考：[COMSOL Safety 官方文档](https://doc.comsol.com/6.3/doc/com.comsol.help.sme/sme_ug_solid.07.042.html)。本程序的第二理论采用单轴线弹性强度换算应变阈值。

验证：tests/strength-criteria.test.js 包含解析应力、泊松耦合、平面外主应变、纯剪切区分、参数缺失、多材料、CPU/GPU结果一致性、材料快照与单位、旧/新TXT读取。C++ Release 核心已重新构建。
