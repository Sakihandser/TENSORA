# 爆破瞬态分析（二维）

> 开启“三维计算”后，爆破页签切换为三维爆破模拟，见 [三维爆破模拟](BLAST_3D.md)。本文描述二维工作区。

二维爆破的计算全部由随包开源求解器完成：**OpenCourant 20261011**（OpenRadioss 延续版，`third_party/opencourant`）做显式动力学、岩体本构、炮孔内产物与空气的 ALE 多物质流动、起爆、吸收边界和阻尼；需要“先静力平衡”时由 **MFEM 4.10**（`third_party/mfem/runtime-win-x64/mfem_prestress.exe`）求解平面应变初始平衡。TENSORA 只把共享的二维 TRI3 网格、材料、约束和载荷转换为求解器输入卡片，启动未修改的可执行程序，并把输出映射回原网格显示。做法与 [三维爆破](BLAST_3D.md)、[流固耦合](FSI.md) 模块一致。

原 TensoraCore 自编二维显式积分核心（`BlastDynamics.cpp`、`GasDynamics.cpp` 及其 JH2 / Singularity-EOS 动态库桥接）已于 2026-11-17 从程序中移除，审查结论见文末“旧核心审查（已移除）”。

## 计算链

| 步骤 | 组件 | 说明 |
| --- | --- | --- |
| 网格转换 | TENSORA | 每个 TRI3 以形心和三条边中点剖分为 3 个四边形（相邻三角形共用边中点），再按厚度 H 拉伸为一层六面体。H 取最小单元尺寸，不降低时间步 |
| 平面应变 | OpenCourant `/BCS` | 全部节点约束 z 向位移；薄片对中面对称，两面面内位移一致，ε_zz = γ_xz = γ_yz = 0，输出含面外应力 σ_zz |
| 岩体单元 | OpenCourant `/BRICK` + `/PROP/SOLID` Isolid=24 | 单点积分 HEPH 六面体（物理沙漏稳定），更新拉格朗日（有限变形）格式 |
| 炮孔气体 | Gmsh 4.15 + OpenCourant ALE `/MAT/LAW51` | 孔内由 Gmsh 生成全四边形网格，边界节点就是孔壁节点；空气与产物为 LAW51 多物质 ALE 单元，与岩体共节点耦合（共用节点自动为拉格朗日节点），`/ALE/GRID/LAPLACIAN` 网格光顺，ALE 网格面外方向固定 |
| 初始平衡 | MFEM 4.10 → `/INIBRI/STRS_FGLO` | 平面应变 `ElasticityIntegrator` + PCG；偏应力写入初始应力，静水压力部分通过初始密度由状态方程承载 |
| 输出 | `anim_to_vtk`、`th_to_csv` | 节点位移/速度、单元应力张量、等效应力、压力、JH2 损伤；全局与气体分部能量时程 |

OpenCourant 也有二维 `/QUAD` 平面应变单元，但其动画与时程输出不含 LAW79（JH2）损伤变量（只在壳与实体单元中实现），所以采用单层实体薄片；这条路径与三维爆破完全相同，可输出损伤、完整应力张量并接受 `/INIBRI` 初始应力。

### 材料

| 爆破本构 | OpenCourant 卡片 | 说明 |
| --- | --- | --- |
| 线弹性 | `/MAT/ELAST`（LAW1） | E、ν、ρ 取自基础材料 |
| JH2 | `/MAT/JOHN_HOLM`（LAW79） | 参数同材料卡；G 为 0 时用 E、ν 换算。LAW79 用 σ_HEL = 1.5(HEL − PHEL) 归一化，输入的“归一化等效应力”与之不同时会给出提示；损伤为本构的一部分，没有单独的损伤开关 |
| Mohr–Coulomb | `/MAT/DPRAG1`（LAW10） | 按平面应变匹配的 Drucker–Prager 锥（α = 3 tanφ/√(9+12 tan²φ)，k = 3c/√(9+12 tan²φ)），拉伸截断写入 P_min；剪胀角、软化和残余强度没有对应项，结果中会列出该提示 |

### 爆源

- **给定孔壁压力**：`/PLOAD` 作用在识别出的实际孔壁上，时程为 p(t) = p_max sin(πt/T_p)（0 ≤ t < T_p），之后为零。压力方向指向岩体。
- **材料参数驱动（产物–空气）**：孔内为 LAW51 两种子材料：空气（`/MAT/HYD_VISC` + `/EOS/POLYNOMIAL`，C4 = C5 = γ − 1，E0 = p0/(γ − 1)）与产物。产物选 JWL 时为 `/MAT/JWL`（E0 = 比内能 × 装药密度，P_CJ = ρD²/(γ+1)），在炮孔中心 `/DFS/DETPOINT` 起爆，相当于沿孔轴同时起爆的线装药；选“理想气体”时为已反应的产物气体（E0 = ρ0 e0）。被装药圆周切过的 ALE 单元按面积分数给定初始体积分数（量化到 1/50），结果中给出装药面积的离散误差。LAW51 需要未反应炸药体积模量，按体积声速 c0 ≈ D/3 估计为 ρ0(D/3)²（TNT 约 8.6 GPa），只影响爆轰波前极短时间，数值记录在结果元数据中。
- 炮孔初始空气压力先作为孔壁载荷参与静力预平衡，起爆后由 ALE 空气单元自然提供。

### 边界、载荷和初始状态

- 边界条件与原工作区一致：沿用原约束 / 自由面 / 固定 / 吸收，可按几何边界逐条覆盖。吸收边界用 OpenCourant `/BCS/NRF`（Lysmer–Kuhlemeyer 法向/切向黏性边界，按相邻单元 ρc_p、ρc_s 计算），只作用于真实外边界的单元面。
- 边中点、形心的约束按 TRI3 线性场继承：两端都固定的边，其中点同样固定。
- 外载荷（点力、分布力、体力的节点载荷）和围压快捷输入 t = −diag(p_x, p_y)n 以 `/CLOAD` 恒定施加，按单位厚度换算到薄片两面节点。
- “先静力平衡，再保持外载荷”：MFEM 在同一四边形网格上求平面应变平衡，再以 `/INIBRI` 写入。没有实际支座时，每个连通体加 3 个静力基准自由度去除刚体位移，并先检查载荷的合力、合力矩是否自平衡，否则报错，不用隐藏支承维持非平衡载荷。“起爆时突然施加外载荷”从零应力开始。
- 质量比例阻尼 α 由 `/DAMP` 作用于岩体节点。

## 使用

1. 展开右上角“专业计算”，勾选“爆破模拟”，在“结构绘制”页创建模型，把炮孔设为圆形外部空气区域，为岩体分配材料。坐标单位为 m。
2. 在“爆破设置”页选择压力来源和装药参数，设置边界、围压、时长与帧数，点击“运行爆破模拟”。程序自动识别实际孔壁（圆周误差 ≤ 3% 半径，至少 6 条边，闭合环）。
3. 进度依次显示：准备卡片（含孔内网格）→ MFEM 预平衡 → Starter 检查 → Engine 计算 → 帧转换。计算可随时取消（终止全部子进程）。
4. “爆破结果”页的回放、TNT 视图、测点、ZIP / PNG 导出与以前相同。结果状态栏会显示 OpenCourant 的提前终止原因（例如单元严重畸变）和卡片换算提示。

### 设置页内容

“爆破设置”页只保留 OpenCourant 计算链实际使用的输入：计算方式与炮孔、炸药（JWL 或理想气体产物；JWL 需要爆速）与间隙气体（理想气体）参数、围压与外载荷、边界、岩体本构卡、模拟时长、质量阻尼、保存帧数和最长计算时间。

旧核心的以下选项已从界面删除，服务端收到时明确拒绝，不做近似替代：

- 平面应力（薄板）：二维爆破只按平面应变计算，平面应力在爆破近区稳定性差、工程意义有限；
- 小变形：OpenCourant 统一采用更新拉格朗日的有限变形格式；
- 轴向开口泄流、连通裂隙均压储气：原自编近似模型，求解器中没有对应物理；
- Noble–Abel、Stiffened Gas 产物 / 间隙气体：无对应卡片；
- 时间步、径向气体单元数、冲击波人工黏性开关、断裂能和“启用损伤演化”：时间步由 OpenCourant 按单元稳定条件确定，冲击波使用求解器默认体积黏性，损伤由所选本构决定。

旧模型（和 JSON 场景文件）载入时，平面应力改为平面应变，非 JWL/理想气体的产物改为理想气体，间隙气体改为理想气体，其余已删除的设置被忽略；炸药库和气体库中旧记录的附加参数同样被忽略。运行前请核对气体参数。

## 输出

结果沿用 FEMBLT02 帧格式，前端无需改动：

- 节点：原 TRI3 顶点的位移、速度（取自求解器节点输出）。
- 单元：每个三角形取其 3 个子单元的面积平均应力 σ_xx、σ_yy、τ_xy、σ_zz 与 JH2 损伤；应变取三角形边界上求解器位移（顶点、边中点）的精确平均梯度，与四边形场一致。
- 帧标量：时间、孔壁压力（给定压力模式为输入时程；气体模式为与孔壁相邻的 ALE 单元面积加权压力）、岩体动能、岩体内能（OpenCourant 全局内能减去气体内能，加 MFEM 预平衡储能）、外力功、沙漏能、最大等效应力和扰动应力。气体模式另有气体内能、动能、传给岩体的能量（初始气体能量 − 当前气体能量）与等效孔半径。能量均换算为单位厚度。
- 元数据：求解器、四边形/ALE 单元数、时间步中位数和最小值、循环数（取自 Engine 结束汇总）、是否到达终止时间、卡片换算提示；结果状态栏显示循环数与时间步，“导出爆破表格与云图（ZIP）”中的 `solver-inputs.json` 记录这些信息。
- 进度：依次显示准备卡片 → MFEM 初始平衡 → OpenCourant 输入检查 → 求解 → 保存帧，进度单调递增并按求解速率估算剩余时间。

Engine 在单元严重畸变时可能提前停止并仍报告 NORMAL TERMINATION，程序按实际到达的物理时间与场量有限性判断是否完成，只保留之前的帧并在状态栏说明。

## 适用范围与限制

- 平面应变截面；不含平面应力、轴对称装药长度方向的流动或泄压。
- 拉格朗日岩体，无单元删除与碎块接触；JH2 损伤为连续损伤带，裂缝不分离，气体不进入裂缝。
- 起爆为平面内点起爆（沿孔轴同时起爆的线装药）。
- 吸收边界为局部黏性边界，斜入射、角点与持续外扩流动会产生反射或约束反力，边界应远离关注区并做边界距离检查。
- 网格尺寸控制应力波、爆轰与损伤带的分辨率，需要做网格收敛检查。数值验证不代替试验标定。

## 旧核心审查（已移除）

原二维核心按 MFEM ex10/ex23 和 `NewmarkSolver` 改写为 β = 0、γ = 1/2 的显式中心差分（速度 Verlet）。移除前的审查结论：

- 积分格式本身正确：位移预测、两次半步速度更新、阻尼项 (M + ½Δt C) 的半隐式处理、固定自由度处理都与中心差分一致，弹性算例时间步二阶收敛，与 OpenCourant 在弹性算例上相差 1–5%。
- 结果“算不对”的主要来源是外围模型而非积分器：默认“小变形”在炮孔近区应变远超 5%（耦合装药孔壁位移达孔径量级）时力学上失效；气体按单一平均半径的一维径向模型与二维岩体耦合；平面应力 JH2 依靠自编厚度迭代。
- “不收敛/算不动”的来源：JH2 与冲击黏性的自适应 CFL 在高压下把时间步压到约 1 ns（耦合装药算例 8 万余步、约 15 分钟）；有限变形模式中任一单元面积比 J < 1e-4 即中止整个计算；有限变形初始平衡迭代不收敛或超过 JH2 静力强度时直接拒绝。

这些问题在 OpenCourant 链路中由求解器本身的有限变形格式、单元稳定时间步、ALE 多物质气体与提前终止处理取代。2026-11-17 起旧核心、其 JH2 / Singularity-EOS 动态库、上游材料核快照（`third_party/openradioss-jh2`、`singularity-eos-runtime`、`cbgeo-materials`、`clawpack-riemann`）以及对应测试和文档均已移出程序；`TensoraCore.exe` 只保留静力计算。
