# TENSORA v1.2.2

Compared with [v1.2.1](https://github.com/Sakihandser/TENSORA/compare/v1.2.1...v1.2.2).

## English

- **3D conditions on CAD geometry.** Define restraints and loads on CAD faces, edges, points on faces, line segments and partial faces before meshing. The mesher includes these regions and the application binds the conditions to the resulting nodes and boundary elements.
- **Distributed loads.** Apply uniform or linearly varying line loads in N/m. Apply linear traction or normal pressure to whole or partial faces using one coordinate axis or independent X, Y and Z gradients. Viewport arrows show local load direction and relative magnitude before and after meshing.
- **ASTM E1820-01 validation.** The README includes the full single-edge bend study with two-dimensional and three-dimensional calculations, fitted geometry factors, mesh checks, and the sensitivity of the free-surface equivalent to its extraction window. All study cases were reproduced with v1.2.2 on the archived meshes.

Download **TENSORA-v1.2.2-windows-x64.zip**, extract the entire archive, and run **TENSORA.exe**. The accompanying SHA-256 file verifies the ZIP.

## 中文

相较于 v1.2.1，本版更新如下。

- **三维 CAD 约束与载荷。** 可在划分网格前，对 CAD 面、边、面上单点、线段和局部面设置约束与载荷。划分网格后，软件将条件绑定到对应的节点和边界单元。
- **分布载荷。** 支持均布及线性变化的线载荷（N/m），以及作用于整面或局部面的线性面力和法向压力。面载荷可沿单一坐标轴变化，也可分别设置 X、Y、Z 梯度。网格划分前后都可通过箭头查看载荷方向与相对强度。
- **ASTM E1820-01 数值验证。** README 收录单边裂纹三点弯曲论文全文，展示二维和三维复现结果、几何因子拟合、网格校验，以及自由表面等效值对测距窗口的敏感性。全部算例均使用 v1.2.2 在归档网格上复算。

下载 **TENSORA-v1.2.2-windows-x64.zip**，完整解压后运行 **TENSORA.exe**。可用随附的 SHA-256 文件校验安装包。
