# TENSORA v1.2.3

[Full comparison with v1.2.2 / 与 v1.2.2 的完整对比](https://github.com/Sakihandser/TENSORA/compare/v1.2.2...v1.2.3)

## English

- **Point probes for 2D and 3D results.** In statics, deformation and blast results, select points on the contour or model or enter coordinates. Save up to eight probes, optionally snap them to mesh nodes, and inspect the available displacement, velocity, stress, strain and damage fields. In deformation and blast runs, select a point on the history curve or a table row to jump to that increment or frame. Export probe values and histories as CSV.
- **3D transient dynamics.** The 3D workspace uses OpenCourant for explicit dynamics and MFEM for initial static equilibrium. Results include section contours, frame playback and JSON export. The material library supports linked cards for linear elasticity, JH2, HJC, Drucker–Prager and Johnson–Cook.
- **Nonlinear deformation and fracture.** The 3D workspace adds Code_Aster for Mazars concrete damage and OOFEM for crack-band fracture. CalculiX material cards add compressible Neo-Hooke and Mooney–Rivlin hyperelasticity and multilinear J2 hardening.
- **Material libraries and documentation.** Long names and notes wrap within table cells. The README links to the archived v1.2.2 software and ASTM E1820 report on Zenodo.

Download **TENSORA-v1.2.3-windows-x64.zip**, extract the entire archive, and run **TENSORA.exe**. The ZIP includes the solver runtimes and a separate SHA-256 checksum is available on the release page.

## 中文

- **二维和三维结果测点查询。** 在静力学、损伤变形和爆破结果中，可从云图或模型选点，也可输入坐标。最多保存 8 个测点，可吸附到网格节点，查询当前结果提供的位移、速度、应力、应变及损伤等量。损伤变形和爆破结果可通过时程曲线或表格跳转到对应增量或帧。测点数值和时程可导出为 CSV。
- **三维瞬态动力学。** 三维工作区使用 OpenCourant 进行显式动力学计算，使用 MFEM 求解初始静力平衡。结果支持剖面云图、逐帧回放和 JSON 导出。材料库支持关联线弹性、JH2、HJC、Drucker–Prager 和 Johnson–Cook 材料卡。
- **非线性变形与断裂。** 三维工作区新增 Code_Aster Mazars 混凝土损伤和 OOFEM 裂带断裂。CalculiX 材料卡新增可压缩 Neo-Hooke、Mooney–Rivlin 超弹性和 J2 多线性硬化。
- **材料库与文档。** 修复材料库中长名称与备注的换行及行高问题。README 已加入 v1.2.2 软件和 ASTM E1820 报告的 Zenodo 归档链接。

下载 **TENSORA-v1.2.3-windows-x64.zip**，完整解压后运行 **TENSORA.exe**。ZIP 内含求解器运行时，发布页另附 SHA-256 校验文件。
