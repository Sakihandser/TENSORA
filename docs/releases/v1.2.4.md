# TENSORA v1.2.4

[Full comparison with v1.2.3 / 与 v1.2.3 的完整对比](https://github.com/Sakihandser/TENSORA/compare/v1.2.3...v1.2.4)

## English

- **2D and 3D fluid–structure interaction.** The new workspace includes a fluid library, boundary and solver settings, and result views. Bundled SU2 supports steady and transient two-way coupling. The one-way workflow transfers wall loads from SU2 to MFEM, with corrected pressure transfer for compressible flow. In 3D, OpenCourant SPH supports explicit transient free-surface problems.
- **3D velocity vectors.** Toggle velocity arrows on visible fluid surfaces and sections, or on SPH particles in the particle view. The 3D result viewer also supports point probes and frame playback.
- **Pre-run checks.** Calculation pages flag configuration problems before solving. The material and fluid libraries check input parameters and link findings to the relevant controls.
- **Examples and desktop startup.** The aerodynamic examples include a 2D NACA 0012 airfoil and a 3D sailplane, with reproducible inputs, velocity contours and von Mises stress plots. Saved models retain their FSI settings when reopened. The Windows launcher suppresses the notification from the bundled Chrome for Testing browser.

Download **TENSORA-v1.2.4-windows-x64.zip**, extract the entire archive, and run **TENSORA.exe**. The package includes the browser and solver runtimes. A separate SHA-256 checksum is available on the release page.

## 中文

- **二维和三维流固耦合。** 新增流体材料库、边界与求解设置、结果页。随包 SU2 支持稳态和瞬态双向耦合，单向耦合由 SU2 向 MFEM 传递壁面载荷，并修复了可压缩流动的压力传递。三维另支持 OpenCourant SPH 自由液面显式瞬态计算。
- **三维速度矢量。** 可在可见流体的外表面和剖面上叠加流速箭头，SPH 粒子视图也可显示流速箭头。三维结果支持测点查询与逐帧回放。
- **计算前检查。** 各计算页面可在求解前提示设置问题，材料库和流体材料库支持参数检查，可从提示定位到相关控件。
- **气动算例与桌面启动。** 新增二维 NACA 0012 翼型和三维滑翔机算例，提供复算输入、流速云图和米塞斯应力云图。重新打开已保存的模型时保留流固耦合设置。Windows 启动器已修复随包 Chrome 测试版的提示横幅。

下载 **TENSORA-v1.2.4-windows-x64.zip**，完整解压后运行 **TENSORA.exe**。便携包内含浏览器与求解器运行时，发布页另附 SHA-256 校验文件。
