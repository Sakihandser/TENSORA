# TENSORA v1.2.7

[Compare v1.2.6 → v1.2.7 / 完整代码对比](https://github.com/Sakihandser/TENSORA/compare/v1.2.6...v1.2.7)

## English

### Local mesh refinement in 2D and 3D

- On the **Analysis** page, define up to 50 zones with individual target element sizes. Choose circles, rectangles or ellipses in 2D, and spheres, boxes or ellipsoids in 3D. Enter the centre coordinates or pick a point in the viewport. The model JSON stores the refinement zones.
- For each zone, choose a growth ratio from 1.05 to 3, or enter the physical width over which the target size increases to the global mesh size. New zones default to a ratio of 1.2. Previously saved zones without transition settings keep the original 1.6 ratio. The controls show the transition width, estimated number of layers or equivalent growth ratio, and the viewport marks the transition boundary.
- Triangle refines the 2D TRI3 mesh in multiple passes against the size field, preserving geometry and material interfaces. Gmsh applies the local size fields to the 3D tetrahedral mesh. The shared editor groups placement and extent separately from size and transition. [3D analysis guide](https://github.com/Sakihandser/TENSORA/blob/v1.2.7/docs/SOLID_3D.md)

### Global mesh sizing and specialty setup

- 2D Analysis now offers **By mesh size**, which uses a target edge length and checks against a safety cap of 1 million nodes. **By node limit** remains the default. Switching to size mode prefills an equivalent size from the current mesh, when available. Changes to sizing settings cause the next automatic mesh generation to place nodes again. ZZ adaptive controls sit in a collapsible group.
- The 2D Damage & Deformation, FSI and Blast setup pages display the current mesh status and link to Analysis. Use Analysis to configure meshing. When a specialty run regenerates a stale mesh, it uses those settings. [FSI guide](https://github.com/Sakihandser/TENSORA/blob/v1.2.7/docs/FSI.md)

### Material bindings and explicit quasi-static deformation

- The **Material bindings** tab appears when a specialty module is enabled. A base material can link to multiple constitutive cards in the deformation or blast material library. Select one active card per library for use in calculations. Links can be edited by dragging connectors or using the card selector. Existing single-card associations are carried forward as active links.
- OpenCourant adds RHT for concrete and rock, CDPM2 concrete damage plasticity and Drucker–Prager cap plasticity. The bundled RHT user-material library supplies the RHT implementation. Nine additional reference card sets are provided in both specialty libraries, with source notes. They are linked as alternatives and can be activated in **Material bindings**.
- **Damage & Deformation** adds an OpenCourant explicit quasi-static path for 2D plane strain and 3D TET4 solids. It supports force and prescribed-displacement control with a linear loading ramp and adaptive dynamic relaxation. Results include displacement, stress, strain, equivalent plastic strain and constitutive damage where the selected law provides them. The run reports its final kinetic-to-internal energy ratio. [Damage & Deformation guide](https://github.com/Sakihandser/TENSORA/blob/v1.2.7/docs/DEFORMATION.md)
- The 2D blast solver can use the active blast-library card. Several classic models resolve cards through the current material bindings at run time. The classic-model guide identifies which models store their deformation cards directly. [Classic-model guide](https://github.com/Sakihandser/TENSORA/blob/v1.2.7/examples/classic-models/README.md)

### Higher limits for 3D linear statics

- The mesh limits rise from 350,000 to **1,000,000 nodes** and from 1.5 million to **5 million tetrahedra**. The stiffness matrix supports up to **32 million node-coupling blocks**. Mesh connectivity and available memory determine the practical limit. Specialty solvers apply their own limits.
- The bundled native PCG executable accepts the larger matrices. Automatic solver selection uses native OpenMP CPU iterations on larger meshes and attempts OpenCL FP64 from 1.2 million tetrahedra, with CPU fallback. [3D solver scope](https://github.com/Sakihandser/TENSORA/blob/v1.2.7/docs/SOLID_3D.md#performance-and-scope)

## 中文

### 二维与三维局部网格加密

- 在**计算**页可添加最多 50 个局部加密区，并为每个区域指定目标单元尺寸。二维支持圆形、矩形、椭圆，三维支持球形、盒形、椭球。中心可输入坐标，也可在视窗拾取。加密区随模型 JSON 保存。
- 每个加密区可按增长率或实际过渡宽度控制网格从局部目标尺寸向全局尺寸的渐变。增长率可设为 1.05–3，新建加密区默认 1.2。旧模型中缺少过渡设置的加密区沿用 1.6。面板显示过渡宽度、估算层数或等效增长率，视窗标出过渡区外缘。
- 二维 Triangle 按尺寸场多轮细化 TRI3 网格，保留几何边界和材料界面。三维 Gmsh 使用局部尺寸场生成四面体网格。二维和三维的加密表单均按位置与范围、尺寸与过渡分组。[三维计算指南](https://github.com/Sakihandser/TENSORA/blob/v1.2.7/docs/SOLID_3D.md)

### 全局网格尺寸与专业计算设置

- 二维基础计算页新增**按网格尺寸**模式，按目标边长布点，安全上限为 100 万节点。**按节点上限**仍为默认模式。已有网格时，切换到尺寸模式会填入等效尺寸。修改划分设置后，下次自动划分会重新布点。ZZ 自适应选项收纳在可折叠分组中。
- 二维损伤变形、流固耦合和爆破设置页显示当前网格状态，并提供前往基础计算页的入口。网格参数在基础计算页设置。启动专业计算时若重新划分过期网格，将使用这套设置。[流固耦合指南](https://github.com/Sakihandser/TENSORA/blob/v1.2.7/docs/FSI.md)

### 材料绑定与显式准静态变形

- 启用专业模块后可打开**材料绑定**页。一个基础材料可绑定损伤变形库或爆破材料库中的多张本构卡，并在每个库中选定一张参与计算的激活卡。可拖动连线或通过卡片选择器编辑关联。旧数据中的单卡关联会保留为激活绑定。
- OpenCourant 新增混凝土与岩石的 RHT、混凝土损伤塑性 CDPM2，以及 Drucker–Prager 帽盖塑性。便携包包含 RHT 用户材料库。两个专业材料库各增加 9 张带来源备注的参考卡，作为备选绑定，可在**材料绑定**页激活。
- **损伤变形**新增 OpenCourant 显式准静态路径，支持二维平面应变和三维 TET4 实体。力控制与规定位移控制均采用线性加载斜坡和自适应动力松弛。按本构输出位移、应力、应变、等效塑性应变和损伤，并报告加载结束时的动能与内能比。[损伤变形指南](https://github.com/Sakihandser/TENSORA/blob/v1.2.7/docs/DEFORMATION.md)
- 二维爆破求解可以使用当前激活的爆破材料卡。部分经典算例也会在运行时读取当前材料绑定。算例指南说明了哪些模型会直接保存损伤变形卡。[经典算例指南](https://github.com/Sakihandser/TENSORA/blob/v1.2.7/examples/classic-models/README.md)

### 三维线弹性静力规模提升

- 节点上限由 35 万提高至 **100 万**，四面体单元上限由 150 万提高至 **500 万**。刚度矩阵最多支持 **3,200 万个节点耦合块**。实际可处理规模取决于网格连接和可用内存，各专业求解器有独立上限。
- 随包原生 PCG 求解器支持扩容后的矩阵。自动模式在较大网格上使用原生 OpenMP CPU 迭代，从 120 万四面体起尝试 OpenCL FP64，失败时回退到 CPU。[三维求解范围](https://github.com/Sakihandser/TENSORA/blob/v1.2.7/docs/SOLID_3D.md#performance-and-scope)
